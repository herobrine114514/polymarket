# 更新审阅与发布说明

审阅日期：2026-10-11。首次发布包含现有应用源码、Claude 新增的研究模型与看板改版，许可证为 MIT。

## 本次更新

- 看板采用侧栏、市场卡片、筛选、明暗主题、模拟权益曲线和运行健康状态；卡片保留“立即审计预测”按钮。
- BTC 五分钟研究增加 Binance 秒级历史数据、因果特征、TWAP 概率基线、对称化 LightGBM、按时间切分的结果预测与盘口回放。
- 慢周期市场研究增加历史价格校准；天气研究增加站点数据、预报误差校正、概率组合、挂单回放、结算边界和历史资金流分析。
- 这些脚本位于 `experiments/`，不会自动晋升为生产模型，不会提交真实订单。

## 验证中需要保留的限制

1. `btc5m_edge_model.py` 的部分五块交叉验证会用到被评估块之后的样本，只能视为离线诊断；不能等同于严格前向验证。同一五分钟窗口内的多条预测也不是独立事件。负延迟的比较是诊断性实验，不是可部署输入。
2. BTC 回放依赖历史最优买卖价和固定延迟，并未完整模拟深度、最低订单量、资金占用或订单回执。代理价格和公开 relay 不能替代独立验证的官方签名结算数据；仍需检查双边行情及参考价格的时间有效性。
3. 慢周期市场虽按采样时间切分并排除跨组重复事件，但没有逐条证明训练标签在当时已经公布。历史中间价加假定价差的收益只是模拟。
4. 天气历史预报与观测的时间戳不等于数据实际首次可用时间。仍需追踪发布、接收、修订和官方结算时间，并处理站点、取整及本地日界线差异。
5. 天气挂单及跟随资金流回放以之后出现的公开成交推定成交机会，无法证明自己的订单能成交，也不完整刻画队列、其他做市商反应和库存风险。
6. `weather_flow_following.py` 中部分所谓事件分组实际按日期聚合；独立样本数量应按实际分组解释。钱包筛选、阈值和模型多次比较还需防范选择偏差。

因此，本次发布不宣称胜率提升、稳定盈利或已经满足实盘条件。更可靠的下一步是冻结候选与基线，逐事件保存当时可见信息，在未来事件上比较 Brier、对数损失和包含费用及未成交的模拟收益。

## 发布前的可运行性修复

- 为 Windows 声明 `tzdata` 依赖，修复新环境缺少 IANA 时区数据库导致的导入失败。
- 将采集器使用的 `.mjs` 文件加入 Python 包资源，避免安装包遗漏。
- 签名篡改测试改为翻转原签名字节中的一位，确保每次都改变签名，消除原先写入固定字节造成的随机空操作。
- 缺少可选 Node SDK 时明确跳过对应研究测试。已有历史冻结签名样本的环境继续核对该样本；首次克隆不包含该本地样本。
